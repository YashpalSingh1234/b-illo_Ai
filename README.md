## Set up your virtual enviourment

command:  python -m venv nameOfVeritual Enviourment

### install requirement.text

command: pip install -r requirement.txt

### Activate Virtual Enviourment

command: nameOfVeritualEnviourmen\Scripts\activate

### Load BackEnd 

command: cd backend

#### run your backend

command: python -m uvicorn app:app --reload

### Frontend Run

Open a new terminal and go inside the ui folder

command: cd ui

#### install npm inside the ui folder

command: install npm

#### load ui

command: npm run dev
